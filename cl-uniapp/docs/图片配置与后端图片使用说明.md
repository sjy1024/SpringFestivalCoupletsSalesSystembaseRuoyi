# 图片配置与后端图片使用说明

## 概述

本系统提供了统一的图片配置管理工具，支持本地图片、CDN图片和后端图片的统一管理。

## 图片配置工具

### 导入方式

```javascript
// 导入图片配置工具
import { 
  getImageURL, 
  getCustomImage, 
  getIcon, 
  getBackendImageURL,
  getUploadedImage,
  checkImage 
} from '../../utils/imageConfig';
```

### 基本使用

#### 1. 获取本地图片

```javascript
// 获取定制类型图片
const customImage = getCustomImage(1, { quality: 'thumbnail' });

// 获取图标
const icon = getIcon('arrowRight');

// 获取通用图片
const banner = getImageURL('common', 'banner', { quality: 'medium' });
```

#### 2. 获取后端图片

```javascript
// 从后端获取图片（后端返回相对路径）
const backendImage = getBackendImageURL('/upload/2024/01/01/abc123.jpg');

// 获取上传的图片
const uploadedImage = getUploadedImage('spring-couplet.jpg', { quality: 'large' });
```

### 在定制页面中使用

#### 1. 导入图片工具

```javascript
import { getCustomImage, getImageURL, getBackendImageURL } from '../../utils/imageConfig';
```

#### 2. 使用后端图片

```javascript
// 在页面方法中使用
async loadBackendImage() {
  try {
    // 假设从API获取的图片路径
    const imagePath = '/upload/custom/spring-couplet.jpg';
    
    // 获取完整URL
    const imageUrl = getBackendImageURL(imagePath, { quality: 'medium' });
    
    // 检查图片是否存在
    const exists = await checkImage(imageUrl);
    
    if (exists) {
      this.setData({
        customImage: imageUrl
      });
    } else {
      // 使用默认图片
      this.setData({
        customImage: getImageURL('common', 'default')
      });
    }
  } catch (error) {
    console.error('加载图片失败:', error);
  }
}
```

```javascript
const envConfigs = {
  [ENV_TYPES.DEVELOPMENT]: {
    name: '开发环境',
    baseURL: 'http://127.0.0.1:8080', // 后端API地址
    // ... 其他配置
  }

```

### 2. 图片路径配置

在 `utils/imageConfig.js` 中配置后端图片路径：

```javascript
const IMAGE_CONFIG = {
  basePaths: {
    // 后端图片路径
    backend: envConfig.baseURL + '/profile/upload'
  }
};
```

## 图片质量配置

系统支持多种图片质量选项：

- `thumbnail`: 缩略图 (200px)
- `medium`: 中等尺寸 (500px) 
- `large`: 大尺寸 (800px)
- `original`: 原图

使用方式：

```javascript
// 获取缩略图
const thumbnail = getBackendImageURL(imagePath, { quality: 'thumbnail' });

// 获取中等尺寸
const medium = getBackendImageURL(imagePath, { quality: 'medium' });

// 获取原图
const original = getBackendImageURL(imagePath, { quality: 'original' });
```

## 图片懒加载

系统支持图片懒加载功能：

```javascript
// 在页面中设置图片懒加载
setupImageLazyLoad() {
  if (typeof wx !== 'undefined' && wx.createIntersectionObserver) {
    this.imageObserver = wx.createIntersectionObserver(this, {
      thresholds: [0.1],
      observeAll: true
    });
    
    this.imageObserver
      .relativeToViewport({ bottom: 100 })
      .observe('.lazy-image', (res) => {
        if (res.intersectionRatio > 0) {
          this.loadImage(res.dataset.index);
        }
      });
  }
}
```

## 错误处理

### 1. 图片不存在处理

```javascript
async loadImageWithFallback(imagePath) {
  try {
    const url = getBackendImageURL(imagePath);
    const exists = await checkImage(url);
    
    if (exists) {
      return url;
    } else {
      // 返回默认图片
      return getImageURL('common', 'default');
    }
  } catch (error) {
    console.error('图片加载失败:', error);
    return getImageURL('common', 'error');
  }
}
```

### 2. 网络错误处理

```javascript
async loadImageWithRetry(imagePath, retryCount = 3) {
  for (let i = 0; i < retryCount; i++) {
    try {
      const url = getBackendImageURL(imagePath);
      const exists = await checkImage(url);
      
      if (exists) {
        return url;
      }
    } catch (error) {
      console.warn(`第${i + 1}次重试失败:`, error);
      
      if (i < retryCount - 1) {
        // 等待后重试
        await new Promise(resolve => setTimeout(resolve, 1000));
      }
    }
  }
  
  // 所有重试都失败，返回默认图片
  return getImageURL('common', 'error');
}
```

## 最佳实践

### 1. 预加载重要图片

```javascript
async preloadImportantImages() {
  const importantImages = [
    getImageURL('common', 'banner'),
    getImageURL('icons', 'cart'),
    getImageURL('icons', 'user')
  ];
  
  try {
    await Promise.all(importantImages.map(url => checkImage(url)));
    console.log('重要图片预加载完成');
  } catch (error) {
    console.warn('图片预加载失败:', error);
  }
}
```

### 2. 使用合适的图片质量

- 列表页：使用 `thumbnail` 或 `medium`
- 详情页：使用 `large` 或 `original`
- 图标：使用原图

### 3. 监控图片加载性能

```javascript
async loadImageWithPerformance(imagePath) {
  const startTime = Date.now();
  
  try {
    const url = getBackendImageURL(imagePath);
    const exists = await checkImage(url);
    
    const loadTime = Date.now() - startTime;
    console.log(`图片加载时间: ${loadTime}ms`);
    
    return exists ? url : getImageURL('common', 'default');
  } catch (error) {
    console.error('图片加载失败:', error);
    return getImageURL('common', 'error');
  }
}
```

## 常见问题

### Q: 后端图片无法显示怎么办？

1. 检查后端URL配置是否正确
2. 检查图片路径是否正确
3. 检查网络连接
4. 检查图片文件是否存在

### Q: 如何切换图片源？

```javascript
// 使用本地图片
const localImage = getImageURL('custom', 'springCouplet');

// 使用后端图片
const backendImage = getBackendImageURL('/upload/custom/spring-couplet.jpg');

// 根据环境自动切换
const image = envConfig.isProd ? 
  getImageURL('custom', 'springCouplet', { useBackend: false }) :
  getBackendImageURL('/upload/custom/spring-couplet.jpg');
```

### Q: 如何添加新的图片分类？

在 `utils/imageConfig.js` 中添加新的分类：

```javascript
categories: {
  // 新增分类
  banners: {
    home: 'banners/home.jpg',
    promotion: 'banners/promotion.jpg'
  }
}
```

使用方式：

```javascript
const homeBanner = getImageURL('banners', 'home');
```
