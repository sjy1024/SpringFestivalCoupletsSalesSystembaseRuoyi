# 优化功能部署指南

## 概述

本文档指导如何部署新创建的优化功能，包括统一请求封装、图片配置工具和优化版定制页面。

## 已完成的优化功能

### 1. 统一请求封装 (`services/_utils/request.js`)
- 支持拦截器、重试机制、缓存、错误处理
- 性能监控集成
- 统一的错误处理
- 支持GET/POST/PUT/DELETE快捷方法

### 2. 图片配置工具 (`utils/imageConfig.js`)
- 统一管理本地、CDN、后端图片
- 支持图片质量控制（缩略图、中等尺寸、大尺寸）
- 后端图片URL生成
- 图片检查和预加载

### 3. 优化版定制页面 (`pages/APP-custom/index-optimized.js`)
- 分阶段数据加载
- 表单验证
- 图片懒加载
- 性能监控
- 错误处理

### 4. 辅助工具
- 错误处理器 (`services/_utils/errorHandler.js`)
- 性能监控工具 (`services/_utils/performance.js`)
- 环境配置 (`config/env.config.js`)

## 部署步骤

### 步骤1: 检查环境配置

1. 打开 `cl-uniapp/config/env.config.js`
2. 确认后端API地址正确：
   ```javascript
   baseURL: 'http://127.0.0.1:8080' // 根据实际后端地址修改
   ```

### 步骤2: 部署统一请求封装

1. **替换现有请求文件**：
   - 备份现有的 `utils/request.js`（如果存在）
   - 删除或重命名旧的请求文件

2. **更新服务文件**：
   - 检查所有使用旧请求封装的服务文件
   - 更新导入语句：
     ```javascript
     // 旧方式
     import request from '../../utils/request';
     
     // 新方式
     import { request, get, post } from '../../services/_utils/request';
     ```

3. **测试API调用**：
   - 测试主要的API接口
   - 验证错误处理功能
   - 检查loading显示

### 步骤3: 部署图片配置工具

1. **检查图片目录结构**：
   ```
   cl-uniapp/static/images/
   ├── custom/          # 定制相关图片
   │   ├── spring-couplet.jpg
   │   ├── fu.jpg
   │   └── horizontal.jpg
   ├── icons/           # 图标
   │   ├── arrow-right.png
   │   ├── cart.png
   │   └── user.png
   ├── goods/           # 商品图片
   │   ├── default.jpg
   │   └── placeholder.jpg
   └── common/          # 通用图片
       ├── logo.png
       ├── banner.jpg
       └── default.jpg
   ```

2. **上传实际图片**：
   - 将实际图片文件上传到对应目录
   - 或配置后端图片路径

3. **更新页面图片引用**：
   - 查找所有硬编码的图片路径
   - 替换为图片配置工具调用

### 步骤4: 部署优化版定制页面

1. **备份原始页面**：
   ```bash
   # 如果存在原始定制页面
   cp cl-uniapp/pages/APP-custom/index.js cl-uniapp/pages/APP-custom/index-backup.js
   ```

2. **替换页面文件**：
   ```bash
   # 将优化版页面重命名为正式文件名
   cp cl-uniapp/pages/APP-custom/index-optimized.js cl-uniapp/pages/APP-custom/index.js
   cp cl-uniapp/pages/APP-custom/index-optimized.wxml cl-uniapp/pages/APP-custom/index.wxml
   cp cl-uniapp/pages/APP-custom/index-optimized.wxss cl-uniapp/pages/APP-custom/index.wxss
   ```

3. **更新页面配置**：
   - 检查 `app.json` 中的页面路径
   - 确保路由配置正确

### 步骤5: 测试功能

```javascript

```

   - 验证数据分阶段加载

2. **表单功能测试**：
   - 测试定制类型选择
   - 测试尺寸选择

### 步骤6: 配置后端图片

#### 6.1 如果使用本地图片

1. 确保图片文件存在于 `static/images/` 目录
2. 在 `utils/imageConfig.js` 中配置正确的路径
3. 测试图片加载

#### 6.2 如果使用后端图片

1. **配置后端API**：
   ```javascript
   // 在 env.config.js 中
   baseURL: 'http://your-backend-domain.com'
   ```

2. **配置图片路径**：
   ```javascript
   // 在 imageConfig.js 中
   backend: envConfig.baseURL + '/profile/upload'
   ```

3. **上传图片到后端**：
   - 通过后端管理界面上传图片
   - 或使用API上传图片

4. **测试后端图片**：
   ```javascript
   // 测试后端图片加载
   const imageUrl = getBackendImageURL('/upload/custom/spring-couplet.jpg');
   console.log('后端图片URL:', imageUrl);
   ```

### 步骤7: 监控和优化

#### 7.1 性能监控

1. **启用性能监控**：
   ```javascript
   // 在 env.config.js 中
   enablePerformance: true
   ```

2. **查看性能报告**：
   - 在控制台查看性能日志
   - 监控关键操作耗时

#### 7.2 错误监控

1. **启用错误跟踪**：
   ```javascript
   // 在 env.config.js 中
   enableErrorTracking: true
   ```

2. **错误处理测试**：
   - 模拟网络错误
   - 测试API错误
   - 验证错误提示

## 常见问题解决

### Q1: 图片无法显示

**可能原因**：
1. 图片路径错误
2. 图片文件不存在
3. 网络问题
4. 跨域问题

**解决方案**：
1. 检查图片路径配置
2. 确认图片文件存在
3. 检查网络连接
4. 配置CORS

### Q2: API请求失败

**可能原因**：
1. 后端API地址错误
2. 网络问题
3. 认证问题
4. 跨域问题

**解决方案**：
1. 检查 `env.config.js` 中的 `baseURL`
2. 检查网络连接
3. 验证token是否正确
4. 配置后端CORS

### Q3: 页面加载缓慢

**可能原因**：
1. 图片太大
2. API响应慢
3. 代码优化不足

**解决方案**：
1. 使用图片压缩
2. 启用图片懒加载
3. 优化API响应
4. 使用分阶段加载

### Q4: 表单验证不工作

**可能原因**：
1. 验证规则错误
2. 事件绑定问题
3. 数据更新问题

**解决方案**：
1. 检查验证规则配置
2. 验证事件绑定
3. 检查setData调用
