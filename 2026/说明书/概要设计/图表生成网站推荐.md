# 图表生成网站推荐（概要设计）

本文件按毕业设计常见图类型汇总推荐网站，优先考虑：上手快、中文兼容、可导出 PNG/SVG/PDF、可用于论文排版。

## 1. 总体架构图 / 部署架构图

- 首选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 适合做系统架构、部署拓扑、组件连接图
  - 自由度高，导出清晰，适合论文最终版
- 备选：[ProcessOn](https://www.processon.com/)
  - 模板多，国内访问稳定，协作方便
- 备选：[Lucidchart](https://www.lucidchart.com/)
  - 组件库丰富，商业化程度高，英文界面为主

## 2. 模块分层图 / 组件关系图

- 首选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 适合画三层架构、模块依赖、包结构
- 备选：[ProcessOn](https://www.processon.com/)
  - 拖拽快，适合课程项目快速出图
- 备选：[Mermaid Live Editor](https://mermaid.live/)
  - 文本生成图，版本可追踪，适合放在代码仓库维护

## 3. 时序图（Sequence Diagram）

- 首选：[PlantUML Online Server](https://www.plantuml.com/plantuml/)
  - 语法成熟，适合接口交互流程描述
- 首选：[SequenceDiagram.org](https://sequencediagram.org/)
  - 专注时序图，界面简单，出图很快
- 备选：[Mermaid Live Editor](https://mermaid.live/)
  - 语法相对简洁，适合轻量流程

## 4. 活动图（Activity Diagram）

- 首选：[PlantUML Online Server](https://www.plantuml.com/plantuml/)
  - 支持分支、并行、泳道，适合业务流程
- 备选：[ProcessOn](https://www.processon.com/)
  - 可视化拖拽，便于答辩前微调布局
- 备选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 手工布局灵活，导出质量高

## 5. 状态机图（State Diagram）

- 首选：[PlantUML Online Server](https://www.plantuml.com/plantuml/)
  - 适合订单状态流转、生命周期建模
- 备选：[Mermaid Live Editor](https://mermaid.live/)
  - 语法简单，适合中小型状态图
- 备选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 手工美化效果好，适合最终排版

## 6. ER 图（数据库实体关系图）

- 首选：[dbdiagram.io](https://dbdiagram.io/)
  - 用 DBML/SQL 直接生成 ER 图，效率最高
- 首选：[drawDB](https://drawdb.app/)
  - 交互式建模体验好，导出方便
- 备选：[QuickDBD](https://www.quickdatabasediagrams.com/)
  - 文本生成 ER 图，上手快
- 备选：[Visual Paradigm Online](https://online.visual-paradigm.com/)
  - 功能完整，适合规范化建模

## 7. 用例图（Use Case Diagram）

- 首选：[StarUML Online / UMLBoard](https://www.umlboard.com/)
  - UML语义贴近标准，适合课程文档
- 备选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 拖拽式快速出图，模板多
- 备选：[ProcessOn](https://www.processon.com/)
  - 适合中文文档场景

## 8. 类图（Class Diagram）

- 首选：[PlantUML Online Server](https://www.plantuml.com/plantuml/)
  - 代码化维护，适合类关系频繁调整
- 备选：[Mermaid Live Editor](https://mermaid.live/)
  - 快速表达类关系，语法轻量
- 备选：[Visual Paradigm Online](https://online.visual-paradigm.com/)
  - UML完整度高，适合严谨展示

## 9. 数据流图 / 流程图（DFD / Flowchart）

- 首选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 自由布局能力强，适合复杂流程
- 备选：[ProcessOn](https://www.processon.com/)
  - 快速画流程并加中文标注
- 备选：[Mermaid Live Editor](https://mermaid.live/)
  - 文本化维护流程逻辑

## 10. 系统边界图 / 上下文图（Context Diagram）

- 首选：[draw.io / diagrams.net](https://app.diagrams.net/)
  - 对外部参与者与系统边界表达清晰
- 备选：[ProcessOn](https://www.processon.com/)
  - 模板多，适合快速成稿
- 备选：[Miro](https://miro.com/)
  - 协作场景强，适合多人讨论后定稿

## 选型建议（按你的当前文档）

- 如果你追求“最终论文排版效果”：优先 `draw.io` 或 `ProcessOn`
- 如果你追求“文本可维护、可版本管理”：优先 `PlantUML` / `Mermaid`
- 如果你当前重点是数据库 ER 图：优先 `dbdiagram.io`
- 你这套文档的推荐组合：  
  `架构/边界/用例/流程 -> draw.io`，`时序/状态/活动 -> PlantUML`，`ER -> dbdiagram.io`
