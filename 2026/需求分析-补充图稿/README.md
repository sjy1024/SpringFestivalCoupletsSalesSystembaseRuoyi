# 需求分析补充图稿（可直接复制使用）

本目录按你最新版需求分析（3.2 八大模块 + 3.6 系统边界）整理。
每个 `.puml` 文件都带有明确标题，打开后可直接复制到 PlantUML 在线工具或 VS Code PlantUML 插件使用。

## 文件清单

- `01-用户模块-用例图.puml`（USER-001~USER-005）
- `02-商品模块-用例图.puml`（GOODS-001~GOODS-006）
- `03-购物车模块-用例图.puml`（CART-001~CART-007）
- `04-订单模块-用例图.puml`（ORDER-001~ORDER-008）
- `05-订单状态流转-活动图.puml`（表3-6、表3-7）
- `06-支付模块-用例图.puml`（PAY-001~PAY-003）
- `07-支付流程-活动图.puml`（3.2.5 支付流程）
- `08-AI服务模块-用例图.puml`（AI-001~AI-005）
- `09-定制模块-用例图.puml`（CUSTOM-001~CUSTOM-006）
- `10-管理模块-用例图.puml`（ADMIN-001~ADMIN-006）
- `11-系统边界-示意图.puml`（3.6 系统包含/不包含）

## 使用方式

1. 复制任意 `.puml` 全文到 https://www.plantuml.com/plantuml/uml/
2. 或在 VS Code / Cursor 安装 PlantUML 插件后直接预览导出 PNG
