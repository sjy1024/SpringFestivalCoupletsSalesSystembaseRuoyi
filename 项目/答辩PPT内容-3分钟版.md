## 第 3 页｜系统总体设计（约 30 秒）

### PPT 上写什么

**标题**：系统总体架构

**架构图（建议画在 PPT 上）**

```
┌─────────────────┐     REST API     ┌──────────────────────┐
│  微信小程序      │ ◄──────────────► │  Spring Boot 后端     │
│  (TDesign)      │                  │  (若依 + MyBatis)     │
└─────────────────┘                  └──────────┬───────────┘
┌─────────────────┐     JWT 鉴权                  │
│  Vue2 管理后台   │ ◄─────────────────────────────┤
│  (Element UI)   │                               │
└─────────────────┘                               ▼
                                         ┌─────────────────┐
                                         │  MySQL + Redis  │
                                         └────────┬────────┘
                                                  │
                                         ┌────────▼────────┐
                                         │  LM Studio 大模型 │
                                         └─────────────────┘
```

**要点**
- 前后端分离，RESTful API 通信
- C 端：`/api/app/*`，deviceId 标识用户（免登录）
- B 端：JWT + Spring Security 权限控制
- AI：本地 LM Studio（OpenAI 兼容接口）

### 口述稿

> 系统采用前后端分离架构。后端基于 Spring Boot 和 MyBatis，管理端使用 Vue2 和 Element UI，小程序采用 TDesign 组件库。C 端通过 deviceId 实现免登录访问，管理端采用 JWT 鉴权。AI 能力由本地 LM Studio 大模型提供推理服务。

## 第 5 页｜功能模块一：电商基础（约 15～20 秒）

### PPT 上写什么

**标题**：电商基础模块

**功能要点**
- **商品**：列表展示、详情查看、上架商品筛选（`/api/app/goods`）
- **购物车**：添加、修改数量、删除、批量结算（`/api/app/cart`）
- **订单**：单商品/多商品创建、模拟支付、确认收货（`/api/app/order`）
- **地址**：收货地址增删改查、默认地址（`/api/app/address`）

**业务规则（可选小字）**
- 订单状态：待支付 → 已支付 → 制作中 → 已完成 / 已取消（0～4）
- 下单时校验库存并扣减；订单明细保存商品名称与价格快照
- 用户以 **deviceId** 标识，免注册登录

**建议配图**：小程序首页、购物车、订单详情截图

### 口述稿

> 电商基础模块覆盖商品浏览、购物车、订单和地址管理。用户可加入购物车批量结算，创建订单后通过模拟支付完成流转；订单采用五态状态机管理，明细表保存价格快照，C 端以 deviceId 关联用户数据。

---

## 第 6 页｜功能模块二：定制服务（约 15～20 秒）

### PPT 上写什么

**标题**：定制服务模块

**功能要点**
- **定制选项**：春联 / 福字 / 横批；尺寸 1.2～2.1 米；联纸材质（含点金加价）
- **内容输入**：上联、下联、横批（可手填，也可从 AI 页一键填入）
- **价格计算**：按尺寸基础价 + 材质加价实时计价（`/api/custom/calculate-price`）
- **方案提交**：写入定制单并进入排队（`/api/custom/submit`）

**智能排队**
- 自动生成 `queueNo`（排队序号）
- 返回 `estimatedTime`（预计完成分钟数）
- 定制单关联主订单 `order_id`，保证数据一致

**建议配图**：定制 Tab 页、提交成功排队弹窗截图

### 口述稿

> 定制模块是系统特色之一。用户选择类型、尺寸和材质，填写春联内容后提交；系统自动计算价格、分配排队号并给出预计完成时间，定制记录与订单关联存储，便于后续制作与查询。

## 第 7 页｜功能模块三：AI 智能（约 15～20 秒）

### PPT 上写什么

**标题**：AI 智能模块

**功能要点**
- **AI 对话**：咨询春联文化、定制流程、价格尺寸（`/api/ai/chat`）
- **一键生成**：按主题生成上联、下联、横批（`/api/ai/generate-couplet`）
- **经典推荐**：内置热门春联模板（`/api/ai/recommend`）
- **填入定制**：生成结果经 `customBridge` 跳转定制 Tab 自动填字

**技术说明（可选小字）**
- 大模型：LM Studio 本地部署（OpenAI 兼容接口）
- 离线降级：关键词回退 + 本地模板，保证可用性
- 对话持久化：`cl_app_ai_chat`（按 deviceId + sessionId）

**建议配图**：AI 对话页、主题 chip、「填入定制」按钮截图

### 口述稿

> AI 模块集成大语言模型，支持自由对话和按主题生成春联。生成后可一键填入定制页，形成「AI 写联 → 选规格 → 提交定制」的业务闭环；模型离线时有关键词回退，保证基本可用。

## 第 8 页｜功能模块四：管理后台（约 15～20 秒）

### PPT 上写什么

**标题**：管理后台模块

**功能要点**
- **商品管理**：增删改查、上下架、库存维护（`/system/goods`）
- **订单管理**：订单列表、状态查看与编辑（`/system/order`）
- **智能助手**：SSE 流式对话，订单/库存/商品数据分析（`/system/assistant`）

**管理端价值**
- 运营人员集中维护商品与订单
- AI 助手辅助数据查询与经营分析
- 与 C 端接口分离，保障后台安全

**建议配图**：商品管理页、智能助手页截图

### 口述稿

> 管理后台基于若依框架实现，管理员可进行商品和订单维护，并通过智能助手以自然语言查询经营数据。管理端采用 JWT 鉴权，与 C 端匿名接口分离，保障系统安全。

## 第 9 页｜系统创新点（约 40 秒，重点页）

### PPT 上写什么

**标题**：系统创新点

1. **行业垂直适配**  
   针对春联定制的类型、尺寸、材质等业务设计，非通用电商简单复制

2. **智能排队系统**  
   定制提交后自动分配排队号，计算预计完成时间，提升服务透明度

3. **AI 春联服务闭环**  
   大模型生成上联/下联/横批 → 一键填入定制页 → 提交进入制作队列

4. **免登录设计**  
   deviceId 标识用户，无需注册登录，符合小程序轻量化使用场景

### 口述稿

> 本系统有四个创新点：第一，围绕春联行业特点做垂直设计；第二，定制订单提交后自动生成排队号和预计完成时间；第三，AI 生成春联并可一键填入定制页，形成业务闭环，这是核心亮点；第四，采用 deviceId 免登录，降低使用门槛。
