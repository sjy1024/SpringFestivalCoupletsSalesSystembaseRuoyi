## 一、项目总览

本仓库是 **春联售卖 / 春节商城类** 的毕设与演示工程（README 中亦称 SpringCouplets-management），采用 **前后端分离**：

| 部分 | 技术 | 路径 | 作用 |
|------|------|------|------|
| 管理后台 + 业务 API | RuoYi-Vue（Spring Boot 2.5 + Vue2 + Element UI） | `RuoYi-Vue/` | 后台管理、权限、定时任务、代码生成；扩展了小程序端 REST 接口（商品、购物车、订单、定制、地址、AI 等） |
| 用户端（小程序形态） | 微信小程序工程（`app.json` 等） | `cl-uniapp/` | 首页、定制、购物车、个人中心、商品/订单分包、AI 对话等 |

根 `pom.xml` 中描述为「春节商城」，版本 RuoYi **3.9.1**。

## 三、`RuoYi-Vue/` 子模块（Maven）

| 模块 | 职责 |
|------|------|
| **`ruoyi-admin`** | Spring Boot **启动入口**、Web 层 Controller（含面向小程序的 `app` 包下接口）。 |
| **`ruoyi-framework`** | 安全、权限、过滤器、AOP、数据源等 **框架层** 装配。 |
| **`ruoyi-system`** | 系统管理与 **业务域** 实现：用户/角色/菜单、以及春联业务相关 domain、mapper、service。 |
| **`ruoyi-common`** | 通用工具、常量、基类、异常等 **公共代码**。 |
| **`ruoyi-quartz`** | **定时任务** 管理与执行。 |
| **`ruoyi-generator`** | 基于 Velocity 模板的 **代码生成**（Java/Mapper/Vue/SQL 等）。 |
| **`ruoyi-ui`** | **管理后台** Vue2 工程（`npm run dev` 启动）。 |

编译产物在各级 **`target/`** 目录，一般可忽略、不入库（若已误提交可考虑清理并加入 `.gitignore`）。
