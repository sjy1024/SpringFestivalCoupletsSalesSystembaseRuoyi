# 添加"已收货"状态操作指南

## 📋 当前订单状态

**现有状态：**
- `0` 待支付
- `1` 已支付
- `2` 制作中
- `3` 已完成
- `4` 已取消

**新增状态：**
- `5` 已收货 ⭐

## 🎯 操作步骤

### 步骤1：在字典管理中添加"已收货"状态

#### 1.1 登录若依后台

1. 启动后端服务（如果还没启动）
2. 启动前端服务（如果还没启动）
3. 浏览器访问：`http://localhost:80`
4. 登录：`admin` / `admin123`

#### 1.2 进入字典管理

1. 点击左侧菜单：**系统管理**
2. 点击：**字典管理**
3. 在搜索框中输入：`cl_order_status`
4. 点击 **"搜索"** 按钮
5. 找到 **"订单状态"** 这一行
6. 点击 **"字典数据"** 按钮（或点击右侧的"字典数据"链接）

#### 1.3 添加"已收货"字典数据

1. 在字典数据列表页面，点击 **"新增"** 按钮
2. 填写字典数据信息：

| 字段 | 值 |
|------|-----|
| **字典标签** | `已收货` |
| **字典键值** | `5` |
| **字典排序** | `6` |
| **是否默认** | `否` |
| **状态** | `正常` |
| **备注** | `用户已收货`（可选） |

3. 点击 **"提交"** 按钮保存

**完成标志：** ✅ 字典数据列表中能看到"已收货"（键值：5）

### 步骤2：更新状态流转逻辑（可选）

如果已经实现了状态流转功能，需要更新流转规则。

#### 2.1 更新状态流转规则

**新的状态流转规则：**

```
待支付(0) → 已支付(1) → 制作中(2) → 已完成(3) → 已收货(5)
                ↓
             已取消(4)
```

**说明：**
- 已完成 → 已收货（用户确认收货）
- 已取消状态不变

#### 2.2 更新后端代码（如果实现了状态流转）

**位置：** `ruoyi-admin/src/main/java/com/ruoyi/web/controller/cl/ClOrderController.java`

**如果使用了状态流转方法，需要更新验证逻辑：**

```java
/**
 * 修改订单状态（带状态流转验证）
 */
@PreAuthorize("@ss.hasPermi('cl:order:edit')")
@Log(title = "订单", businessType = BusinessType.UPDATE)
@PutMapping("/changeStatus")
public AjaxResult changeStatus(@RequestBody ClOrder clOrder)
{
    ClOrder order = clOrderService.selectClOrderByOrderId(clOrder.getOrderId());
    if (order == null) {
        return error("订单不存在");
    }
    
    String oldStatus = order.getStatus();
    String newStatus = clOrder.getStatus();
    
    // 状态流转验证
    // 待支付 → 已支付
    if ("0".equals(oldStatus) && "1".equals(newStatus)) {
        // 允许
    }
    // 已支付 → 制作中
    else if ("1".equals(oldStatus) && "2".equals(newStatus)) {
        // 允许
    }
    // 制作中 → 已完成
    else if ("2".equals(oldStatus) && "3".equals(newStatus)) {
        // 允许
    }
    // 已完成 → 已收货 ⭐ 新增
    else if ("3".equals(oldStatus) && "5".equals(newStatus)) {
        // 允许
    }
    // 待支付/已支付 → 已取消
    else if (("0".equals(oldStatus) || "1".equals(oldStatus)) && "4".equals(newStatus)) {
        // 允许
    }
    else {
        return error("状态流转不合法：" + getStatusName(oldStatus) + " → " + getStatusName(newStatus));
    }
    
    return toAjax(clOrderService.updateClOrder(clOrder));
}

/**
 * 获取状态名称
 */
private String getStatusName(String status) {
    Map<String, String> statusMap = new HashMap<>();
    statusMap.put("0", "待支付");
    statusMap.put("1", "已支付");
    statusMap.put("2", "制作中");
    statusMap.put("3", "已完成");
    statusMap.put("4", "已取消");
    statusMap.put("5", "已收货");  // ⭐ 新增
    return statusMap.getOrDefault(status, "未知");
}
```
