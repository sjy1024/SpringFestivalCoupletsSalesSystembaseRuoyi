## 🔧 小程序后端代码位置

### 位置：`RuoYi-Vue/ruoyi-admin/src/main/java/com/ruoyi/web/controller/app/`

**完整路径：**
```
RuoYi-Vue/
└── ruoyi-admin/
    └── src/
        └── main/
            └── java/
                └── com/
                    └── ruoyi/
                        └── web/
                            └── controller/
                                └── app/          # ⭐ 小程序后端接口目录
                                    ├── AppAuthController.java      # 登录认证
                                    ├── AppGoodsController.java     # 商品接口

                                    ├── AppCustomOrderController.java # 定制订单接口
                                    └── AppAiController.java        # AI聊天接口
```

### 为什么放在这里？

1. **统一管理**：所有 Controller 都在 `controller` 目录下
2. **区分业务**：`app` 目录专门放小程序接口，`cl` 目录放后台管理接口
3. **符合若依规范**：遵循若依框架的代码组织方式

## 📝 详细目录说明

### 后端代码（若依项目）

#### 1. Controller 层

**位置：** `ruoyi-admin/src/main/java/com/ruoyi/web/controller/app/`

**文件命名规范：**
- 小程序接口：`App` + 功能名 + `Controller`
- 例如：`AppOrderController.java`、`AppGoodsController.java`

**示例：**
```java
// AppOrderController.java
@RestController
@RequestMapping("/api/app/order")
public class AppOrderController extends BaseController {
    // 小程序订单接口
}
```

#### 2. Service 层

**位置：** `ruoyi-system/src/main/java/com/ruoyi/system/service/`

**说明：**
- 可以复用现有的 Service（如 `IClOrderService`）
- 或者创建新的 Service（如 `IAppOrderService`）

**推荐：** 复用现有 Service，减少代码重复

#### 3. Mapper 层

**位置：** `ruoyi-system/src/main/java/com/ruoyi/system/mapper/`

**说明：**
- 复用现有的 Mapper（如 `ClOrderMapper`）
- 不需要创建新的 Mapper

#### 4. Domain 层（实体类）

**位置：** `ruoyi-system/src/main/java/com/ruoyi/system/domain/`

**说明：**
- 复用现有的实体类（如 `ClOrder`）
- 如果需要 DTO（数据传输对象），可以创建在 `com.ruoyi.cl.dto` 包下

---

### 前端代码（uni-app 项目）

#### 1. 页面（pages）

**位置：** `uni-app-miniprogram/pages/`

**说明：**
- 每个功能模块一个目录
- 每个页面一个 `.vue` 文件

#### 2. 组件（components）

**位置：** `uni-app-miniprogram/components/`

**说明：**
- 可复用的组件放在这里
- 例如：商品卡片、订单项等

#### 3. 工具函数（utils）

**位置：** `uni-app-miniprogram/utils/`

**重要文件：**
- `api.js` - API 接口定义
- `request.js` - 请求封装（添加 Token、错误处理等）

#### 4. 静态资源（static）

**位置：** `uni-app-miniprogram/static/`

**说明：**
- 图片、图标等静态资源

## 🔗 接口路径规范

### 后端接口路径

**统一前缀：** `/api/app/`

**示例：**
- 商品列表：`GET /api/app/goods/list`
- 商品详情：`GET /api/app/goods/{id}`
- 创建订单：`POST /api/app/order/create`
- 订单列表：`GET /api/app/order/list`
- 模拟支付：`POST /api/app/order/mockPay`
- AI聊天：`POST /api/app/ai/chat`

### 前端请求配置

**在 `utils/request.js` 中配置：**

```javascript
const BASE_URL = 'http://localhost:8080'  // 开发环境
// const BASE_URL = 'https://your-domain.com'  // 生产环境

const request = (options) => {
  return new Promise((resolve, reject) => {
    uni.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data || {},
      header: {
        'Content-Type': 'application/json',
        ...options.header
      },
      success: (res) => {
        resolve(res.data)
      },
      fail: (error) => {
        reject(error)
      }
    })
  })
}

export default request
```
