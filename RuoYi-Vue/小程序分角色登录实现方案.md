# 小程序分角色登录实现方案

## 📋 当前设计 vs 分角色登录

### 当前设计（deviceId 方式）

**特点：**
- 不需要登录，使用 `deviceId` 标识用户
- 简单快速，适合演示
- 无法区分用户角色
- 无法实现权限控制

**适用场景：**
- MVP 版本
- 演示系统
- 不需要用户管理的场景

---

### 分角色登录设计

**特点：**
- 需要登录，使用账号密码
- 可以区分不同角色（普通用户、管理员等）
- 可以实现权限控制
- 可以管理用户信息

**适用场景：**
- 正式版本
- 需要用户管理的场景
- 需要权限控制的场景

---

## 🎯 角色设计建议

### 方案1：简单角色（推荐）

**角色类型：**
1. **普通用户**（customer）
   - 可以浏览商品
   - 可以下单
   - 可以查看自己的订单
   - 可以使用 AI 聊天

2. **管理员**（admin）
   - 可以管理商品
   - 可以管理订单
   - 可以查看所有订单
   - 可以管理用户（可选）

---

### 方案2：多角色（复杂）

**角色类型：**
1. **普通用户**（customer）
2. **VIP 用户**（vip）
3. **管理员**（admin）
4. **超级管理员**（super_admin）

## 🏗️ 实现方案

### 方案A：复用若依用户系统（推荐）⭐⭐⭐

**优点：**
- 复用若依现有的用户、角色、权限系统
- 代码改动小
- 权限管理完善

**实现步骤：**

#### 1. 创建小程序用户角色

在若依后台：
1. 进入 **系统管理 → 角色管理**
2. 点击 **"新增"**
3. 创建角色：
   - 角色名称：`小程序用户`
   - 角色权限：`cl:goods:list`、`cl:order:create` 等

#### 2. 创建小程序用户表（可选）

如果需要单独管理小程序用户，可以创建新表：


#### 3. 实现登录接口

**位置：** `ruoyi-admin/src/main/java/com/ruoyi/web/controller/app/AppAuthController.java`

```java
@RestController
@RequestMapping("/api/app/auth")
public class AppAuthController extends BaseController {
    
    @Autowired
    private IClMiniprogramUserService userService;
    
    /**
     * 小程序登录
     */
    @PostMapping("/login")
    public AjaxResult login(@RequestBody LoginBody loginBody) {
        // 1. 验证用户名密码
        ClMiniprogramUser user = userService.selectByUsername(loginBody.getUsername());
        if (user == null || !passwordMatches(loginBody.getPassword(), user.getPassword())) {
            return error("用户名或密码错误");
        }
        
        // 2. 检查用户状态
        if ("1".equals(user.getStatus())) {
            return error("用户已被停用");
        }
        
        // 3. 生成 Token（JWT）
        String token = JwtUtils.createToken(user.getUserId(), user.getUsername());
        
        // 4. 返回用户信息和 Token
        Map<String, Object> data = new HashMap<>();
        data.put("token", token);
        data.put("user", user);
        data.put("role", user.getRoleType()); // 0=普通用户，1=管理员
        
        return success(data);
    }
    
    /**
     * 获取用户信息
     */
    @GetMapping("/userInfo")
    public AjaxResult getUserInfo(@RequestHeader("Authorization") String token) {
        // 从 Token 中解析用户ID
        Long userId = JwtUtils.getUserId(token);
        ClMiniprogramUser user = userService.selectByUserId(userId);
        return success(user);
    }
}
```

#### 4. 小程序端登录页面

**位置：** `uni-app-miniprogram/pages/login/index.vue`

```vue
<template>
  <view class="login-container">
    <view class="login-form">
      <view class="title">登录</view>
      
      <input 
        v-model="username" 
        placeholder="请输入用户名" 
        class="input"
      />
      
      <input 
        v-model="password" 
        type="password" 
        placeholder="请输入密码" 
        class="input"
      />
      
      <button @click="handleLogin" class="login-btn">登录</button>
      
      <view class="register-link" @click="goRegister">
        还没有账号？立即注册
      </view>
    </view>
  </view>
</template>

<script>
import { login } from '@/utils/api'

export default {
  data() {
    return {
      username: '',
      password: ''
    }
  },
  methods: {
    async handleLogin() {
      if (!this.username || !this.password) {
        uni.showToast({
          title: '请输入用户名和密码',
          icon: 'none'
        })
        return
      }
      
      try {
        const res = await login({
          username: this.username,
          password: this.password
        })
        
        if (res.code === 200) {
          // 保存 Token 和用户信息
          uni.setStorageSync('token', res.data.token)
          uni.setStorageSync('userInfo', res.data.user)
          uni.setStorageSync('role', res.data.role)
          
          // 跳转到首页
          uni.switchTab({
            url: '/pages/index/index'
          })
        } else {
          uni.showToast({
            title: res.msg || '登录失败',
            icon: 'none'
          })
        }
      } catch (error) {
        uni.showToast({
          title: '登录失败，请重试',
          icon: 'none'
        })
      }
    },
    
    goRegister() {
      uni.navigateTo({
        url: '/pages/register/index'
      })
    }
  }
}
</script>
```

#### 5. 请求拦截器（添加 Token）

**位置：** `uni-app-miniprogram/utils/request.js`

```javascript
// 请求拦截器
const request = (options) => {
  return new Promise((resolve, reject) => {
    // 获取 Token
    const token = uni.getStorageSync('token') || ''
    
    // 添加 Token 到请求头
    options.header = {
      ...options.header,
      'Authorization': token ? `Bearer ${token}` : ''
    }
    
    uni.request({
      ...options,
      success: (res) => {
        // Token 过期，跳转到登录页
        if (res.statusCode === 401) {
          uni.removeStorageSync('token')
          uni.removeStorageSync('userInfo')
          uni.reLaunch({
            url: '/pages/login/index'
          })
          return
        }
        resolve(res.data)
      },
      fail: (error) => {
        reject(error)
      }
    })
  })
}

export default request
```

### 前端权限控制

**在小程序中根据角色显示不同功能：**

```vue
<template>
  <view>
    <!-- 普通用户和管理员都可以看到 -->
    <view @click="goGoodsList">商品列表</view>
    <view @click="goOrderList">我的订单</view>

  computed: {
    isAdmin() {
      const role = uni.getStorageSync('role')

    }
  }
}
```

## 🔄 兼容旧设计（deviceId）

**如果已经有使用 deviceId 的用户，可以兼容：**

```java
/**
 * 小程序登录（兼容 deviceId）
 */
@PostMapping("/login")
public AjaxResult login(@RequestBody LoginBody loginBody) {
    // 如果传了 deviceId，且没有用户名密码，使用 deviceId 登录
    if (loginBody.getDeviceId() != null && loginBody.getUsername() == null) {
        // 使用 deviceId 登录（匿名用户）
        return anonymousLogin(loginBody.getDeviceId());
    }
    
    // 正常用户名密码登录
    return normalLogin(loginBody);
}
```
