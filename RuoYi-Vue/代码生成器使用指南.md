# 若依代码生成器使用指南

## 🎯 目标
用代码生成器生成商品管理的后台页面（增删改查）

---

## 📝 详细步骤

### 第1步：登录若依后台
1. 启动后端服务（如果还没启动）
2. 启动前端服务（如果还没启动）
3. 浏览器访问：`http://localhost:80`（或你的端口）
4. 登录：`admin` / `admin123`（或你的账号密码）

---

### 第2步：进入代码生成器
1. 点击左侧菜单：**系统工具**
2. 点击：**代码生成**
3. 你会看到一个表格，显示已导入的表

---

### 第3步：导入商品表
1. 点击右上角的 **"导入"** 按钮
2. 在弹出的对话框中，选择 **"cl_goods"** 表
3. 点击 **"确定"**
4. 表格中会出现 `cl_goods` 这一行

---

### 第4步：配置字段信息（重要！）
1. 点击 `cl_goods` 这一行的 **"修改"** 按钮
2. 你会看到所有字段的配置界面

#### 需要配置的字段（按你的需求）：

**基本信息：**
- **基本信息 → 生成模块**：`cl`（或 `couplet`，你的业务模块名）
- **基本信息 → 生成包路径**：`com.ruoyi.cl`（或 `com.ruoyi.couplet`）
- **基本信息 → 作者**：你的名字
- **基本信息 → 生成方式**：`zip压缩包`（推荐）或 `自定义路径`

**字段配置（重点）：**

| 字段名 | 列表显示 | 查询条件 | 表单类型 | 字典类型（可选） |
|--------|---------|---------|---------|----------------|
| `goods_name` | ✅ 是 | ✅ 是 | 输入框 | - |
| `goods_type` | ✅ 是 | ✅ 是 | 下拉框 | `cl_goods_type`（如果配置了字典） |
| `goods_price` | ✅ 是 | ❌ 否 | 数字输入框 | - |
| `stock` | ✅ 是 | ❌ 否 | 数字输入框 | - |
| `cover_image` | ✅ 是 | ❌ 否 | 图片上传 | - |
| `description` | ❌ 否 | ❌ 否 | 文本域 | - |
| `rating` | ✅ 是 | ❌ 否 | 数字输入框 | - |
| `status` | ✅ 是 | ✅ 是 | 下拉框 | `cl_goods_status`（如果配置了字典） |
| `sort_order` | ✅ 是 | ❌ 否 | 数字输入框 | - |
| `create_time` | ✅ 是 | ✅ 是 | 日期选择器 | - |
| `remark` | ❌ 否 | ❌ 否 | 文本域 | - |

**说明：**
- **列表显示**：是否在表格中显示这一列
- **查询条件**：是否可以作为搜索条件
- **表单类型**：新增/编辑时用什么控件
- **字典类型**：如果配置了字典，会自动显示文本（如：0→上架，1→下架）

---

### 第5步：生成代码
1. 配置完成后，点击 **"提交"** 保存配置
2. 回到代码生成列表页
3. 勾选 `cl_goods` 这一行
4. 点击 **"生成代码"** 按钮
5. 选择 **"zip压缩包"** 方式（推荐）
6. 下载 zip 文件

---

### 第6步：解压并复制代码
解压下载的 zip 文件，你会看到以下目录结构：

```
ruoyi/
├── main/
│   ├── java/
│   │   └── com/ruoyi/cl/          # 后端代码
│   │       ├── domain/            # 实体类
│   │       ├── mapper/            # Mapper接口
│   │       ├── service/           # Service接口和实现
│   │       └── controller/        # Controller
│   └── resources/
│       └── mapper/cl/              # MyBatis XML
└── vue/
    └── cl/                        # 前端代码
        └── goods.vue              # 商品管理页面
```

#### 复制后端代码：
1. **实体类**：复制到 `RuoYi-Vue/ruoyi-system/src/main/java/com/ruoyi/system/domain/`
2. **Mapper接口**：复制到 `RuoYi-Vue/ruoyi-system/src/main/java/com/ruoyi/system/mapper/`
3. **Service**：复制到 `RuoYi-Vue/ruoyi-system/src/main/java/com/ruoyi/system/service/`
4. **Controller**：复制到 `RuoYi-Vue/ruoyi-admin/src/main/java/com/ruoyi/web/controller/`
5. **Mapper XML**：复制到 `RuoYi-Vue/ruoyi-system/src/main/resources/mapper/system/`

#### 复制前端代码：
1. **页面文件**：复制到 `RuoYi-Vue/ruoyi-ui/src/views/cl/`（需要先创建 `cl` 目录）
2. **API文件**：复制到 `RuoYi-Vue/ruoyi-ui/src/api/cl/`（需要先创建 `cl` 目录）

---

### 第7步：添加菜单（让页面能访问）
1. 登录若依后台
2. 进入 **系统管理 → 菜单管理**
3. 点击 **"新增"** 按钮
4. 填写菜单信息：

```
菜单类型：菜单
菜单名称：商品管理
显示顺序：1
路由地址：cl/goods
组件路径：cl/goods/index
权限字符：cl:goods:list
```

5. 点击 **"确定"** 保存
6. 刷新页面，左侧菜单应该能看到"商品管理"

---

### 第8步：测试
1. 点击左侧菜单 **"商品管理"**
2. 应该能看到商品列表页面（可能是空的）
3. 点击 **"新增"** 按钮，测试能否添加商品
4. 测试编辑、删除功能

---

## ⚠️ 常见问题

### 问题1：生成代码后找不到菜单
- **解决**：检查第7步是否添加了菜单
- **检查**：菜单的"路由地址"和"组件路径"是否正确

### 问题2：页面报错404
- **解决**：检查前端代码是否复制到正确位置
- **检查**：路由地址是否和菜单配置一致

### 问题3：字段显示为0/1而不是文字
- **解决**：配置字典类型（第4步）
- **或者**：先不配置字典，后续再优化

### 问题4：导入表时找不到cl_goods
- **解决**：检查表是否真的创建成功
- **检查**：数据库连接是否正确
