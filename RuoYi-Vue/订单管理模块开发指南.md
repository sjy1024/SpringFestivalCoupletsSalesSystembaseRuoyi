开发订单管理模块，包括：

## 🗄️ 数据库表结构

### 1. 订单表（cl_order）

**表结构：**
```sql
cl_order (
  order_id          BIGINT(20)      -- 订单ID（主键）
  order_no          VARCHAR(32)      -- 订单号（唯一）
  device_id         VARCHAR(64)      -- 设备ID（小程序端标识）
  order_type        CHAR(1)         -- 订单类型（0普通订单 1定制订单）
  total_amount      DECIMAL(10,2)   -- 总价
  status            CHAR(1)         -- 订单状态（0待支付 1已支付 2制作中 3已完成 4已取消）
  receiver_name     VARCHAR(50)     -- 收货人
  receiver_phone     VARCHAR(20)     -- 收货电话
  receiver_address   VARCHAR(200)    -- 收货地址
  create_time       DATETIME        -- 创建时间
  update_time       DATETIME        -- 更新时间
  ...
)
```

### 2. 订单明细表（cl_order_item）

**表结构：**
```sql
cl_order_item (
  item_id           BIGINT(20)      -- 明细ID（主键）
  order_id          BIGINT(20)      -- 订单ID（外键）
  goods_id          BIGINT(20)      -- 商品ID
  goods_name        VARCHAR(100)    -- 商品名称（快照）
  goods_price       DECIMAL(10,2)   -- 商品价格（快照）
  quantity          INT(11)         -- 数量
  subtotal          DECIMAL(10,2)   -- 小计
  ...
)
```

订单号可以设置为只读，或者添加复制功能。

**详细实现指南：** 参考 `订单号优化实现指南.md`

**快速实现：**

1. **表单中订单号只读**：
   ```vue
   <el-form-item label="订单号" prop="orderNo">
     <el-input v-model="form.orderNo" readonly />
   </el-form-item>
   ```

2. **列表中添加复制功能**：
   ```vue
   <el-table-column label="订单号" align="center" prop="orderNo">
     <template slot-scope="scope">
       <el-link
         type="primary"
         :underline="false"
         @click="handleCopyOrderNo(scope.row.orderNo)"
         style="cursor: pointer;"
       >
         {{ scope.row.orderNo }}
         <i class="el-icon-document-copy" style="margin-left: 4px;"></i>
       </el-link>
     </template>
   </el-table-column>
   ```

3. **添加复制方法**：
   ```javascript
   async handleCopyOrderNo(orderNo) {
     try {
       if (navigator.clipboard && navigator.clipboard.writeText) {
         await navigator.clipboard.writeText(orderNo);
         this.$modal.msgSuccess('订单号已复制到剪贴板');
       } else {
         // 降级方案
         const textArea = document.createElement('textarea');
         textArea.value = orderNo;
         textArea.style.position = 'fixed';
         textArea.style.left = '-999999px';
         document.body.appendChild(textArea);
         textArea.select();
         document.execCommand('copy');
         document.body.removeChild(textArea);
         this.$modal.msgSuccess('订单号已复制到剪贴板');
       }
     } catch (err) {
       this.$modal.msgError('复制失败，请手动复制');
     }
   }
   ```

### 第5步：实现小程序端订单接口

#### 5.1 创建 AppOrderController

**位置：** `ruoyi-admin/.../controller/app/AppOrderController.java`

**接口列表：**
1. `POST /api/app/order/create` - 创建订单
2. `POST /api/app/order/mockPay` - 模拟支付
3. `GET /api/app/order/list` - 订单列表（按 deviceId 过滤）
4. `GET /api/app/order/{id}` - 订单详情（可选）

#### 5.2 创建订单接口

**功能：**
- 接收：商品ID、数量、deviceId
- 创建订单 + 订单明细
- **扣库存**（下单即扣）
- 生成订单号

**逻辑：**
1. 验证商品是否存在、是否上架
2. 验证库存是否充足
3. 创建订单记录
4. 创建订单明细记录
5. 扣减商品库存
6. 返回订单信息

#### 5.3 模拟支付接口

**功能：**
- 接收：订单ID
- 修改订单状态：`0`（待支付）→ `1`（已支付）

#### 5.4 订单列表接口

**功能：**
- 接收：deviceId（查询参数）
- 返回：该用户的订单列表
- 支持状态筛选（可选）

## 🔑 关键技术点

### 1. 订单号生成

**方式1：时间戳 + 随机数**
```java
String orderNo = System.currentTimeMillis() + String.valueOf((int)(Math.random() * 1000));
```

**方式2：日期 + 序列号**
```java
String orderNo = DateUtils.dateTimeNow() + String.format("%04d", sequence);
```

### 2. 库存扣减

**注意：**
- 下单时立即扣库存
- 需要判断库存是否充足
- 使用数据库锁防止并发问题

### 3. 订单明细快照

**原因：**
- 商品信息可能变更（价格、名称）
- 订单明细需要保存下单时的商品信息

**实现：**
- 在创建订单明细时，保存商品的当前信息（名称、价格）

### 4. deviceId 管理

**小程序端：**
- 首次启动生成 deviceId
- 存储到本地（uni.setStorageSync）
- 后续请求都带上 deviceId

**后端：**
- 通过 deviceId 查询用户的订单
- 不需要登录认证

## 📊 订单状态流转

```
待支付(0) → 已支付(1) → 制作中(2) → 已完成(3)
                ↓
             已取消(4)
```

**状态说明：**
- `0` 待支付：订单刚创建，等待支付
- `1` 已支付：支付完成，等待制作
- `2` 制作中：正在制作商品
- `3` 已完成：订单完成，可以收货
- `4` 已取消：订单被取消
