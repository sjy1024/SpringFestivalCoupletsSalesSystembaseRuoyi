# 若依前端 - 自定义图标添加指南

## 📌 两种图标使用方式

### 方式1：使用 Element UI 内置图标（推荐，最简单）

Element UI 提供了丰富的内置图标，直接使用即可，无需额外配置。

#### 使用方法：
```vue
<el-button icon="el-icon-图标名">按钮文字</el-button>
```

### 方式2：使用自定义 SVG 图标（更灵活）

如果需要使用完全自定义的图标，可以添加 SVG 文件。

#### 步骤1：准备 SVG 文件

1. 准备你的 SVG 图标文件（例如：`goods.svg`）
2. SVG 文件格式示例：
```svg
<svg width="128" height="128" xmlns="http://www.w3.org/2000/svg">
  <path d="你的SVG路径数据"/>
</svg>
```

#### 步骤2：放置 SVG 文件

将 SVG 文件放到：
```
ruoyi-ui/src/assets/icons/svg/
```

例如：`ruoyi-ui/src/assets/icons/svg/goods.svg`

#### 步骤3：在代码中使用

**方法A：在按钮中使用（替换 icon 属性）**
```vue
<el-button>
  <svg-icon icon-class="goods" style="margin-right: 5px;" />
  商品管理
</el-button>
```

**方法B：在表单标签中使用**
```vue
<el-form-item label="商品名称">
  <template slot="label">
    <svg-icon icon-class="goods" style="margin-right: 5px;" />
    商品名称
  </template>
  <el-input v-model="form.goodsName" />
</el-form-item>
```

**方法C：在表格列标题中使用**
```vue
<el-table-column label="商品名称" prop="goodsName">
  <template slot="header">
    <svg-icon icon-class="goods" style="margin-right: 5px;" />
    商品名称
  </template>
</el-table-column>
```

#### 注意事项：
- SVG 文件名就是 `icon-class` 的值（不需要 `.svg` 后缀）
- 图标会自动注册，无需手动导入
- 如果修改了 SVG 文件，需要重启前端服务

## 🎨 实际应用示例

### 示例1：修改商品管理按钮图标

**当前代码：**
```vue
<el-button
  type="primary"
  plain
  icon="el-icon-plus"
  size="mini"
  @click="handleAdd"
>新增</el-button>
```

**改为购物车图标：**
```vue
<el-button
  type="primary"
  plain
  icon="el-icon-shopping-cart-2"
  size="mini"
  @click="handleAdd"
>新增商品</el-button>
```

### 示例2：在表单标签中添加图标

```vue
<el-form-item label="商品名称" prop="goodsName">
  <template slot="label">
    <svg-icon icon-class="shopping" style="margin-right: 5px;" />
    商品名称
  </template>
  <el-input v-model="form.goodsName" placeholder="请输入商品名称" />
</el-form-item>
```

### 示例3：在搜索框前添加图标

```vue
<el-form-item label="商品名称" prop="goodsName">
  <el-input
    v-model="queryParams.goodsName"
    placeholder="请输入商品名称"
    clearable
  >
    <i slot="prefix" class="el-input__icon el-icon-search"></i>
  </el-input>
</el-form-item>
```

## 📝 快速参考

### Element UI 图标快速查找
1. 访问：https://element.eleme.cn/#/zh-CN/component/icon
2. 找到你想要的图标
3. 复制图标类名（例如：`el-icon-goods`）
4. 在代码中使用：`icon="el-icon-goods"`

### SVG 图标快速添加
1. 准备 SVG 文件
2. 放到 `ruoyi-ui/src/assets/icons/svg/` 目录
3. 使用：`<svg-icon icon-class="文件名（不含.svg）" />`
4. 重启前端服务

---

## 💡 推荐

- **日常使用**：优先使用 Element UI 内置图标（方式1），简单快捷
- **特殊需求**：需要完全自定义的图标时，使用 SVG 图标（方式2）

## 🔧 常见问题

**Q: 图标不显示怎么办？**
A: 
- Element UI 图标：检查图标类名是否正确（`el-icon-xxx`）
- SVG 图标：检查文件是否在正确目录，重启前端服务

**Q: 如何调整图标大小？**
A: 
- Element UI 图标：通过按钮的 `size` 属性控制
- SVG 图标：通过 CSS `style="width: 20px; height: 20px;"` 控制

**Q: 如何改变图标颜色？**
A: 
- Element UI 图标：通过按钮的 `type` 属性或 CSS `color` 控制
- SVG 图标：通过 CSS `color` 或 `fill` 控制
