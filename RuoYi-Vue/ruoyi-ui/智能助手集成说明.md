# 智能助手集成说明

## 📋 概述

智能助手已经开发完成，现在需要将其集成到后台管理系统中。

## 🎯 集成步骤

### 1. 添加路由配置

在 `ruoyi-ui/src/router/index.js` 中添加智能助手路由：

```javascript
{
  path: '/assistant',
  component: Layout,
  hidden: false,
  children: [
    {
      path: 'index',
      component: () => import('@/views/system/assistant/index'),
      name: 'Assistant',
      meta: { 
        title: '智能助手', 
        icon: 'chat-dot-round',
        noCache: true
      }
    }
  ]
}
```

### 2. 在首页添加快捷入口

在 `ruoyi-ui/src/views/index_modern.vue` 的 `quickActions` 数组中添加：

```javascript
{
  id: 3,  // 注意：ID 要递增，不要重复
  title: '智能助手',
  desc: 'AI 驱动的智能管理',
  icon: 'el-icon-chat-dot-round',
  color: 'rgba(102, 126, 234, 0.85)',  // 紫色
  path: '/assistant/index',
  permission: 'system:assistant:view'
}
```

**具体位置：** 在 `data()` 方法的 `quickActions` 数组中添加，大约在第 229 行附近。

### 3. 配置权限（可选）

如果需要权限控制，在若依后台管理系统中：

1. 进入 **系统管理 > 菜单管理**
2. 新增菜单：
   - 菜单名称：智能助手
   - 路由地址：assistant
   - 组件路径：system/assistant/index
   - 权限标识：system:assistant:view
   - 菜单图标：chat-dot-round

3. 为需要的角色分配权限

## 📁 文件说明

1. **前端页面**

| 接口 | 方法 | 说明 | 权限 |
|------|------|------|------|
| `/system/assistant/chat/stream` | POST | 流式对话 | system:assistant:chat |
| `/system/assistant/chat` | POST | 普通对话 | system:assistant:chat |
| `/system/assistant/analyze/orders` | GET | 订单分析 | system:assistant:analyze |
| `/system/assistant/analyze/inventory` | GET | 库存分析 | system:assistant:analyze |

| `/system/assistant/overview` | GET | 数据概览 | system:assistant:view |
| `/system/assistant/health` | GET | 健康检查 | 无 |

## 🔧 故障排查

### 1. AI 服务不可用

**问题：** 提示 "AI 服务连接失败"

**解决：**
```bash
# 检查 Ollama 是否运行
curl http://localhost:11434/api/tags

# 重启 Ollama
ollama serve
```

### 2. 权限不足

**问题：** 提示 "权限不足"

**解决：**
- 检查用户是否有 `system:assistant:*` 权限
- 在菜单管理中为角色分配权限

### 3. 流式输出不工作

**问题：** 消息不是逐字显示

**解决：**
- 检查浏览器是否支持 Fetch API
- 检查后端是否正确返回 SSE 格式

## 📝 注意事项

1. **性能优化**
   - AI 响应时间取决于模型大小和硬件性能
   - 建议使用较小的模型（如 gemma3:4b）以获得更快响应

2. **安全性**
   - 所有接口都需要登录认证
   - 建议配置权限控制
   - 不要在生产环境中使用 `@Anonymous` 注解

3. **用户体验**
   - 流式输出提供更好的用户体验
   - 建议添加加载动画和错误提示
   - 支持清空对话历史
