# 若依前端 - 红色新年主题修改指南

> **目标**：把若依后台管理系统改成红色新年主题风格

---

## 📍 需要修改的文件（3个核心文件）

### 1. **Element UI 主题色**（最重要）
**文件路径**：`ruoyi-ui/src/assets/styles/element-variables.scss`

**修改内容**：
```scss
/* theme color - 改成红色系 */
$--color-primary: #DC143C;        // 深红色（主色调）
// 或者用更喜庆的红色：
// $--color-primary: #FF1744;     // 亮红色
// $--color-primary: #C41E3A;     // 中国红

$--color-success: #13ce66;         // 成功色（绿色，保持不变）
$--color-warning: #FF6B35;        // 警告色（橙红色，更符合新年）
$--color-danger: #DC143C;         // 危险色（红色，与主色一致）
```

**效果**：所有按钮、链接、选中状态都会变成红色

---

### 2. **基础颜色变量**（侧边栏、菜单等）
**文件路径**：`ruoyi-ui/src/assets/styles/variables.scss`

**修改内容**：
```scss
// base color - 改成红色系
$blue:#DC143C;              // 主蓝色改成红色
$light-blue:#FF1744;        // 浅蓝色改成亮红色
$red:#DC143C;               // 红色（保持不变或加深）
$pink: #FF6B9D;             // 粉色（新年氛围）
$green: #30B08F;            // 绿色（保持不变）
$tiffany: #4AB7BD;          // 青色（保持不变）
$yellow:#FFD700;            // 金色（新年元素）
$panGreen: #30B08F;         // 绿色（保持不变）

// 菜单背景色（可选，改成红色系）
$base-menu-background:#8B0000;        // 深红色背景（暗红色）
$base-menu-color:#FFE4E1;             // 菜单文字颜色（浅红色/米白色）
$base-menu-color-active:#FFFFFF;      // 激活菜单文字颜色（白色）
$base-logo-title-color: #FFFFFF;      // Logo标题颜色（白色）

// 子菜单背景色
$base-sub-menu-background:#A52A2A;    // 子菜单背景（红褐色）
$base-sub-menu-hover:#DC143C;         // 子菜单悬停（深红色）
```

**效果**：侧边栏菜单会变成红色系

---

### 3. **登录页背景**（可选，但很加分）
**文件路径**：`ruoyi-ui/src/views/login.vue`

找到 `<style>` 标签，修改 `.login` 类的背景：


## 📝 修改步骤（5分钟完成）

### 步骤1：修改 Element UI 主题色
1. 打开 `ruoyi-ui/src/assets/styles/element-variables.scss`
2. 找到 `$--color-primary: #1890ff;` 这一行
3. 改成 `$--color-primary: #DC143C;`（或你喜欢的红色）
4. 保存文件

### 步骤2：修改基础颜色变量（可选）
1. 打开 `ruoyi-ui/src/assets/styles/variables.scss`
2. 找到 `$blue:#324157;` 这一行
3. 改成 `$blue:#DC143C;`
4. 如果想改侧边栏，修改 `$base-menu-background` 等变量
5. 保存文件

### 步骤3：重启前端服务
```bash
# 在 ruoyi-ui 目录下
npm run dev
# 或者
npm run serve
```

### 步骤4：查看效果
- 刷新浏览器，应该能看到按钮、链接都变成红色了
- 如果改了侧边栏颜色，侧边栏也会变红

## 🎯 快速测试（1分钟）

这样你就能立刻看到效果，如果满意再继续改其他颜色。
